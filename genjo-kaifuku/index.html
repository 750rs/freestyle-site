原状回復とは（2020年民法改正で明文化）

賃貸における「原状回復」とは、入居者が退去する際に借主の故意・過失や通常の使用を超える使い方によって生じた損耗を元に戻すことです。2020年4月施行の改正民法（第621条）で、通常損耗と経年劣化は借主の原状回復義務に含まれないことが条文として明確になりました。

つまり「退去したら部屋を新品同様に戻す」のではなく、普通に住んでいて生じた劣化はオーナー負担、借主の不注意で生じた汚損は借主負担という区分が原則です。この区分の実務基準になっているのが、国土交通省の「原状回復をめぐるトラブルとガイドライン」です。

📌 借主負担とする場合でも、請求できるのは「毀損部分の最小単位」までです。クロスなら㎡単位が原則で、色柄を合わせる必要がある場合は「その面（一面）」まで。部屋全体の張替え費用を借主に請求することは、原則としてできません。

経過年数（耐用年数）と負担割合

借主負担となる損耗でも、設備や内装には経過年数による価値の減少が考慮されます。ガイドラインでは、入居時の価値を100%として耐用年数で直線的に減少し、耐用年数を超えると残存価値1円として扱います。

空室期間を最短にする原状回復の段取り

原状回復で最も大きなコストは、工事費ではなく空室期間の家賃損失です。家賃6万円の部屋が1ヶ月空けば6万円、退去から工事完了まで3週間かかれば約4.5万円の損失です。FreeStyleでは以下の段取りで、退去から最短3日で募集開始できる状態を目指します。

  1. 退去日が決まった時点でご連絡：退去前でも、間取り・築年・入居年数・分かっている損耗を伺い、工程を仮押さえします。
  2. 退去日に立会・実測：退去立会代行をご利用いただければ、施工職人が立会と同時に実測し、写真記録と見積書を当日〜翌日にお出しします。
  3. 見積承認 → 翌日着工：クロス → 床 → クリーニング → エアコン洗浄の順に連続した日程で施工します。
  4. 完了写真をLINEで報告：立会不要。完了写真は募集用の室内写真にも使えます。
  5. 敷金精算：見積書を「貸主負担分」「借主負担分」に分けて作成できるため、借主様への説明資料としてそのまま使えます。

入居付けにつながる「原状回復＋α」

単に元に戻すだけでなく、数千円〜数万円の追加で募集写真の印象を変える工夫があります。

  • アクセントクロス：リビングの1面だけ1000番台の色柄クロスに。追加費用は数千円〜1万円台で、内見時の第一印象が変わります。
  • 水回りのクッションフロアを木目・タイル調に：古い柄の床は築年数以上に古く見えます。クッションフロア張替えは㎡3,000円〜。
  • LDK・玄関をフロアタイルに：耐久性が高く、次の退去で張り替えなくて済むため長期的にはコストダウンになります。フロアタイル張替え参照。
  • エアコン洗浄済みを募集条件に明記：入居後のクレームで多い「エアコンの臭い」を予防できます。エアコン洗浄は1式12,000円。

よくある質問

退去後、部屋全体のクロス張替え費用を借主に請求できますか？
原則できません。借主負担は「毀損部分の最小単位」までで、クロスは㎡単位、色合わせが必要でも一面までが目安です。さらに入居6年超であれば残存価値1円として扱われ、借主負担分はほぼゼロになります。全面張替えは基本的にオーナー負担のリフォーム費用と考えてください。
ハウスクリーニング費用は借主に負担させられますか？
ガイドラインでは原則貸主負担です。契約書に「退去時クリーニング費用◯円を借主が負担する」と金額・内容を具体的に明示し、借主が納得して合意した特約がある場合に限り借主負担が認められます。
原状回復工事の見積りを「貸主負担」「借主負担」で分けてもらえますか？
はい、可能です。現地確認時に損耗の原因を確認し、ガイドラインの考え方に沿って分けた見積書をお出しします。最終的な負担区分の判断はオーナー様・管理会社様にお願いしています。
退去から募集開始まで最短どれくらいですか？
退去日に立会・実測 → 翌日見積承認 → 翌日着工 → 1R〜1Kなら着工から1〜2日で工事完了・クリーニングという流れで、最短3日程度で募集開始できる状態になります。繁忙期（2〜3月、7〜9月）は枠が埋まりやすいため、退去予定が決まった時点でのご連絡をおすすめします。
名古屋市外の物件も対応できますか？
南区・港区・熱田区・中川区を中心に名古屋市全域は出張費無料で対応しています。豊明・東海・知多・大府など隣接市も内容次第で対応可能です。
